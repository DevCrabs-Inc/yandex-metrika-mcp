# Настройки

Все настройки необязательны: сервер запускается без них, в том числе без токена. Неверное значение останавливает запуск с понятной ошибкой.

| Переменная                | Значения (по умолчанию)                   | Назначение                                                                                            |
| ------------------------- | ----------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `YM_MCP_CLIENT_ID`        | ClientID (встроенное приложение DevCrabs) | Своё OAuth-приложение для входа через браузер                                                         |
| `YM_MCP_OAUTH_PORTS`      | `47613,47614,47615`                       | Порты локального callback; должны совпадать с Redirect URI приложения                                 |
| `YANDEX_METRIKA_TOKEN`    | —                                         | Готовый токен для серверов и контейнеров (подключение `conn_env`)                                     |
| `YM_MCP_ALLOWED_COUNTERS` | все                                       | Ограничение счётчиков для `conn_env`, через запятую                                                   |
| `YM_MCP_SECRET_STORE`     | `auto`                                    | `auto`/`keychain` — системное хранилище; `file` — незашифрованный файл только для вашего пользователя |
| `YM_MCP_DATA_DIR`         | см. ниже                                  | Каталог состояния, выгрузок и файла секретов                                                          |
| `YM_MCP_API_LANG`         | `ru`                                      | Язык подписей в ответах API (`ru` или `en`)                                                           |
| `YM_MCP_PRIVACY`          | `safe`                                    | `safe` удаляет query-строки из URL в подписях; `full` оставляет как есть                              |
| `YM_MCP_AUTO_RESUME`      | `false`                                   | Продолжать прерванные выгрузки при запуске                                                            |
| `YM_MCP_DEMO`             | `true`                                    | Показывать демо-подключение `conn_demo`                                                               |
| `YM_MCP_LOG_LEVEL`        | `info`                                    | Уровень журнала в stderr: `debug`, `info`, `warn`, `error`                                            |

Каталог данных по умолчанию:

- macOS: `~/Library/Application Support/yandex-metrika-mcp`;
- Windows: `%LOCALAPPDATA%\yandex-metrika-mcp`;
- Linux: `$XDG_DATA_HOME/yandex-metrika-mcp` или `~/.local/share/yandex-metrika-mcp`.

## Встроенные ограничения

| Что                                     | Значение                                           |
| --------------------------------------- | -------------------------------------------------- |
| Строк в одном ответе отчёта             | до 200 (по умолчанию 20)                           |
| Размер ответа инструмента               | до 48 КБ; при обрезке указывается причина и курсор |
| Строк на период при сравнении сегментов | 100 крупнейших                                     |
| Интервалов во временном ряду            | до 400; рядов по сегментам — до 10                 |
| Одновременных запросов к API на аккаунт | 2 (у Яндекса лимит 3)                              |
| Запросов `/stat/v1/data` на аккаунт     | 180 за 5 минут (у Яндекса лимит 200)               |
| Запросов в секунду                      | 10 (у Яндекса лимит 30 с одного IP)                |
| Повторов запроса при сбое               | до 3, с паузами; общий лимит времени — 60 секунд   |

Квоты Яндекса общие для всех приложений аккаунта. Если несколько клиентов запущены одновременно, у каждого процесса своя очередь.
