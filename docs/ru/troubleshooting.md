# Решение проблем

Начните с `npx -y @devcrabs/yandex-metrika-mcp doctor` (с флагом `--network` дополнительно проверяется сеть). Отчёт не содержит токенов, названий счётчиков и данных; перед отправкой в issue всё равно просмотрите его.

## Коды ошибок

| Код                                         | Что значит                                               | Что делать                                                                 |
| ------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------- |
| `AUTH_REQUIRED`                             | Нет такого подключения                                   | `metrika_status`, затем `metrika_connect`                                  |
| `AUTH_EXPIRED`                              | Яндекс больше не принимает токен                         | `metrika_connect` с тем же `connection_id`                                 |
| `AUTH_NOT_CONFIGURED`                       | Вход через браузер не настроен или нет хранилища токенов | `auth import-token`, `YANDEX_METRIKA_TOKEN` или `YM_MCP_SECRET_STORE=file` |
| `ACCESS_DENIED`                             | У аккаунта нет доступа к счётчику                        | Проверьте ID; попросите владельца выдать доступ на просмотр                |
| `COUNTER_NOT_ALLOWED`                       | Счётчик не выбран для этого подключения                  | `auth allow` или повторный вход с выбором счётчиков                        |
| `INVALID_QUERY`                             | Неверные поля, период или фильтр                         | Исправьте запрос; список полей — `metrika_catalog`                         |
| `UNSUPPORTED_COMBINATION`                   | Такое сочетание полей не поддерживается                  | Уберите лишние поля                                                        |
| `QUALITY_REQUIREMENT_NOT_MET`               | Строгий режим, а API вернул выборку                      | Сократите период или используйте `accuracy: "balanced"`                    |
| `TIMEZONE_UNKNOWN`                          | У счётчика не определён часовой пояс                     | Укажите его в настройках счётчика                                          |
| `QUOTA_EXCEEDED`                            | Квота Яндекса исчерпана                                  | Подождите до `retry_at`; суточная квота сбрасывается в 00:00 UTC           |
| `UPSTREAM_UNAVAILABLE` / `UPSTREAM_TIMEOUT` | Яндекс недоступен или не ответил вовремя                 | Повторите позже; можно `cache: "allow_stale"`                              |
| `UPSTREAM_SCHEMA_CHANGED`                   | Ответ API не соответствует ожидаемому                    | Сообщите в issue с версией сервера                                         |
| `RESULT_LIMIT_REACHED`                      | Ответ слишком большой                                    | Сузьте запрос или используйте экспорт                                      |
| `CURSOR_EXPIRED` / `CURSOR_MISMATCH`        | Курсор устарел или от другого запроса                    | Повторите запрос без курсора                                               |
| `JOB_NOT_FOUND` / `ARTIFACT_NOT_FOUND`      | Нет такой выгрузки у этого подключения                   | Проверьте ID через `metrika_get_job`                                       |
| `ARTIFACT_EXPIRED`                          | Файл удалён по сроку хранения                            | Запустите выгрузку заново                                                  |
| `STORAGE_LIMIT`                             | Превышен лимит хранилища или мало места                  | `jobs clean`, освободите место                                             |
| `IDEMPOTENCY_CONFLICT`                      | Ключ уже использован с другими условиями                 | Новый `idempotency_key`                                                    |
| `INTERNAL_ERROR`                            | Непредвиденная ошибка                                    | Смотрите stderr-журнал по `request_id` и сообщите в issue                  |

## Частые ситуации

- **Ссылка входа не открывается.** Она работает только на том компьютере, где запущен сервер, и действует 10 минут. Если порты 47613–47615 заняты, задайте другие через `YM_MCP_OAUTH_PORTS` (их нужно добавить в Redirect URI своего приложения).
- **Linux без графической оболочки.** Системного хранилища паролей нет: используйте `YANDEX_METRIKA_TOKEN` или `YM_MCP_SECRET_STORE=file`.
- **Цифры не совпадают с интерфейсом.** Смотрите раздел о сверке в [корректности данных](data-quality.md#сверка-с-интерфейсом-метрики).
- **Целей нет в списке.** Если у счётчика нет целей, это не ошибка: отчёты о трафике работают.
- **Журнал.** Сервер пишет журнал в stderr в формате JSON. Аргументы инструментов, токены и тела ответов в журнал не попадают. Подробный журнал включается так: `YM_MCP_LOG_LEVEL=debug`.
