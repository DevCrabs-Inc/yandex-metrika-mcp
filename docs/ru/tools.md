# Инструменты и сценарии

Ассистент сам выбирает инструменты. Таблица нужна, чтобы понимать, что происходит, и формулировать вопросы точнее.

| Инструмент                 | Что делает                                                                                          |
| -------------------------- | --------------------------------------------------------------------------------------------------- |
| `metrika_status`           | Подключения, состояние выгрузок и следующий шаг. Работает без входа.                                |
| `metrika_connect`          | Даёт одноразовую ссылку для входа через браузер. С `connection_id` — повторный вход.                |
| `metrika_disconnect`       | Отключает аккаунт на этом компьютере: удаляет токен и кэш, отменяет выгрузки.                       |
| `metrika_list_counters`    | Счётчики аккаунта: ID, название, сайт, часовой пояс, уровень доступа.                               |
| `metrika_describe_counter` | Часовой пояс и цели счётчика с ID. Цели с одинаковыми названиями помечаются.                        |
| `metrika_catalog`          | Пресеты, метрики (единицы и правила агрегации), группировки, пресеты периодов.                      |
| `metrika_run_report`       | Отчёт за период: пресет или свои метрики и группировки, фильтры, сортировка, до 200 строк на вызов. |
| `metrika_compare_periods`  | Сравнение двух периодов при одинаковых условиях: абсолютное, процентное и в п.п.                    |
| `metrika_run_timeseries`   | Динамика по дням, неделям или месяцам с точными границами интервалов.                               |
| `metrika_export_report`    | Фоновая выгрузка всех строк в CSV или JSON.                                                         |
| `metrika_get_job`          | Состояние и прогресс выгрузки, путь к готовому файлу.                                               |
| `metrika_cancel_job`       | Отмена выгрузки.                                                                                    |
| `metrika_read_artifact`    | Чтение готового файла частями до 32 КБ.                                                             |

## Пресеты отчётов

| Пресет          | Содержимое                                                                |
| --------------- | ------------------------------------------------------------------------- |
| `overview`      | Визиты, посетители, просмотры, отказы, глубина, время на сайте            |
| `acquisition`   | То же по источникам трафика и их детализации                              |
| `landing_pages` | По страницам входа (домен и путь)                                         |
| `devices`       | По типам устройств                                                        |
| `geography`     | По странам и городам                                                      |
| `goals`         | Достижения, целевые визиты и конверсия выбранных целей (нужны `goal_ids`) |

К любому пресету можно добавить `goal_ids`: появятся целевые визиты и конверсия по этим целям. Цели всегда указываются по ID.

## Периоды

Отчёт по умолчанию строится за последние 7 завершённых дней, сравнение — за две последние полные ISO-недели (понедельник–воскресенье), ряд — за последние 28 завершённых дней по дням. Все даты считаются в часовом поясе счётчика. «Сегодня» доступно только по явному запросу и помечается как незавершённый период.

## Готовые сценарии (prompts)

В клиентах, которые поддерживают prompts, они доступны как команды:

- `weekly_review` — недельный обзор: трафик, источники, посадочные страницы, цели;
- `traffic_drop` — где сконцентрировано падение визитов или целей;
- `landing_conversion` — какие посадочные страницы приводят целевые визиты.

## Как спрашивать

- Называйте сайт или счётчик, если подключено несколько.
- Для целей указывайте ID или попросите ассистента сначала показать список целей.
- Если нужна точность при больших периодах, оставьте строгий режим. Если готовы к оценке по выборке, скажите об этом явно: ассистент передаст `accuracy: "balanced"`.
