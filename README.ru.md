# Yandex Metrika MCP

MCP-сервер для **Яндекс Метрики** только на чтение. Подключите его к Claude, Cursor, VS Code, Codex или другому MCP-клиенту и спрашивайте про трафик, источники, посадочные страницы и цели. В каждом ответе есть точные даты, часовой пояс счётчика, признак семплирования, фильтры и происхождение данных, поэтому цифры можно проверить.

> Статус: **1.0.0-beta.1**. Все возможности первой версии реализованы и покрыты тестами на синтетических данных и имитации API. Сверка с интерфейсом Метрики на живых счётчиках и проверка в разных клиентах ещё идут.

## Что умеет

- **Вход через браузер.** Не нужно создавать своё OAuth-приложение и вставлять токен; токен не попадает в чат.
- **Проверяемые цифры.** Периоды — календарные даты в часовом поясе счётчика, по умолчанию только завершённые дни. Строгий режим точности не выдаёт семплированные данные за точные. Итоги берутся из API, а не складываются из видимых строк.
- **Несколько аккаунтов и клиентов агентства.** Подключения изолированы, у каждого свой список счётчиков.
- **Полная выгрузка.** Фоновый экспорт всех строк в CSV/JSON с контрольными суммами, manifest-файлом и продолжением после перезапуска.
- **Небольшой понятный набор.** 13 инструментов и 3 готовых сценария. Только чтение: сервер не может менять счётчики, цели и доступы.

## Быстрый старт

Нужен Node.js 22.13 или новее.

```bash
npx -y @devcrabs/yandex-metrika-mcp setup --client claude-desktop
```

Вместо `claude-desktop` можно указать `cursor`, `vscode`, `windsurf`, `codex` или `claude-code`. Перезапустите клиент и попросите: «Подключи Яндекс Метрику и сравни последние две недели по источникам трафика». Ассистент вызовет `metrika_connect` и даст ссылку для входа.

Попробовать без аккаунта: всегда доступно демо-подключение `conn_demo` с синтетическими данными.

## Примеры вопросов

- «Сравни две последние полные недели по визитам и целевым визитам цели 3001».
- «Какие посадочные страницы дают больше всего заявок по цели X за прошлый месяц?»
- «Покажи динамику визитов по неделям с начала квартала».
- «Выгрузи все источники трафика за октябрь в CSV для Excel».
